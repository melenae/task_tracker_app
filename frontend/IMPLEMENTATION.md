# Реализованный функционал фронтенда

## ✅ Что реализовано:

### 1. **Аутентификация**
- Страница входа (`/login`)
- Контекст аутентификации (AuthContext)
- Защищенные маршруты (PrivateRoute)
- Автоматическая проверка авторизации

### 2. **Навигация**
- Layout компонент с навигационным меню
- Роутинг через React Router
- Активные ссылки в меню

### 3. **Задачи (Issues)** - Полный функционал
- **Список задач** (`/issues`)
  - Табличный вид
  - Канбан доска
  - Фильтрация по проектам
  - Переключение между видами
- **Создание задачи** (`/issues/create`)
  - Форма с полями: название, описание, статус, приоритет, компания, исполнитель, супервайзер
- **Детальная страница** (`/issues/:id`)
  - Просмотр задачи
  - Редактирование задачи
  - Изменение статуса
  - Комментарии (просмотр и добавление)

### 4. **Проекты** (`/projects`)
- Список проектов в виде карточек
- Отображение менеджера и даты создания

### 5. **Пользователи** (`/users`)
- Таблица со всеми пользователями
- Отображение: ID, имя, email, роль, телефон

### 6. **Аккаунты** (`/accounts`)
- Список аккаунтов в виде карточек
- Отображение slug, менеджера, даты создания

### 7. **Компании** (`/companies`)
- Список компаний в виде карточек

### 8. **Услуги** (`/services`)
- Таблица с услугами
- Отображение цены, времени проверки и дедлайна

### 9. **Базы данных** (`/databases`)
- Таблица с базами данных
- Отображение пути, сервера, компании

## 📁 Структура проекта:

```
frontend/src/
├── services/
│   └── api.js              # API клиент для всех endpoints
├── context/
│   └── AuthContext.js      # Контекст аутентификации
├── components/
│   ├── Layout.js          # Основной layout с навигацией
│   └── Layout.css
├── pages/
│   ├── Login.js           # Страница входа
│   ├── IssuesList.js      # Список задач (таблица + канбан)
│   ├── IssueDetail.js     # Детальная страница задачи
│   ├── IssueCreate.js     # Создание задачи
│   ├── ProjectsList.js    # Список проектов
│   ├── UsersList.js       # Список пользователей
│   ├── AccountsList.js    # Список аккаунтов
│   ├── CompaniesList.js  # Список компаний
│   ├── ServicesList.js    # Список услуг
│   ├── DatabasesList.js   # Список баз данных
│   └── *.css              # Стили для страниц
└── App.js                 # Главный компонент с роутингом
```

## 🔧 API Интеграция

Все API вызовы централизованы в `services/api.js`:
- `authAPI` - авторизация
- `issuesAPI` - задачи
- `projectsAPI` - проекты
- `usersAPI` - пользователи
- `accountsAPI` - аккаунты
- `companiesAPI` - компании
- `servicesAPI` - услуги
- `databasesAPI` - базы данных
- `commentsAPI` - комментарии
- `projectTeamsAPI` - команды проектов
- `clientTeamsAPI` - команды клиентов

## 🎨 Особенности UI:

1. **Канбан доска** - визуальное представление задач по статусам
2. **Адаптивный дизайн** - работает на разных размерах экрана
3. **Цветовая индикация** - статусы и приоритеты имеют цветовую кодировку
4. **Интерактивность** - hover эффекты, плавные переходы

## 🚀 Запуск:

```bash
cd frontend
npm start
```

Приложение будет доступно на http://localhost:3000
